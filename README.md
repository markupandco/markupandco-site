# markupandco.com

Static site for Markup & Co., deployed by Netlify from this repo (publish directory: repo root, no build command).

- `index.html` – homepage (templates showcase)
- `audit/` – website health audit page (Netlify form)
- `whatnot-fee-calculator/`, `depop-fee-calculator/` – free calculator pages (self-contained HTML)
- `thanks/` – landing page for the fee-updates email form
- `assets/` – images and listing videos

To deploy: commit and push to `main`.
